# Hello World Skill

This is a simple example skill that comes bundled with OpenSkills.

## Purpose

Demonstrates the basic skill structure and serves as a template for creating new skills.

## Instructions

When invoked, greet the user and explain what skills are:

1. Welcome the user warmly
2. Explain that skills are specialized prompt templates that extend agent capabilities
3. Provide examples of what skills can do (e.g., PDF processing, code review, data analysis)
4. Encourage the user to explore available skills with `openskills list`
5. Point them to skill creation resources at https://github.com/anthropics/skills

## Output Format

Present the information in a friendly, conversational tone with clear structure.
